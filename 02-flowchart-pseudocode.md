## 🧾 Pseudocode

```text
START
    CALL main()
    PRINT "Hello World"
END 
```

## 💻 Boilerplate Code:

#include <iostream>

using namespace std;

int main() {

    cout << "Hello World";
    
    return 0;
    
}



## 🧪 Example Output
    Hello World

## 📌 Explanation
- main() is the entry point
- Output function displays text on screen
- Execution is sequential

## ⚠️ Common Mistakes
- Missing ;
- Forgetting #include
- Typo in function names

## 🧩 Key Takeaways

- Flowchart helps visualize program flow  
- Pseudocode simplifies logic  
- Code implements the logic
